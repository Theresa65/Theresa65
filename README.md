## My focus

I am building a portfolio at the intersection of BIM development, workflow automation, and AI integration for architecture, engineering, and construction.

My interests include reducing repetitive model tasks, improving BIM data quality, and connecting model information to useful analysis and reporting.

## Areas I am developing

| Area | Workflow focus |
| :--- | :--- |
| **BIM development** | Revit extensions, model data, and reusable tools |
| **BIM automation** | Parameter checks, documentation, and structured exports |
| **AI integration** | Model-data questions, grounded answers, and human-reviewed actions |

## Portfolio

My [BIM portfolio](https://github.com/Theresa65/BIM_Repository) is the intended home for documented projects and demonstrations.

For each published project, I aim to include:
